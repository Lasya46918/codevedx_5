# Project 5 — Smart Recommendation System

## Objective
Recommend movies based on a user-provided genre, description, or a movie title.

## Features
- User preference input.
- Content-based filtering.
- TF-IDF feature representation.
- Cosine similarity scoring.
- Ranked recommendations and score output.

## Run
```bash
pip install -r ../requirements.txt
python main.py
```

The included movie list is a small demonstration dataset. Similarity scores indicate text similarity, not guaranteed personal enjoyment.
